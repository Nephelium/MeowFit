# 深色日历、底部导航与循环进度设计

## 目标

修复日历深色模式把不同指标统一显示为绿色的问题；将底部主导航改成清晰、现代的非像素风格；让首页“今日状态”进度条在超过目标后继续表达超额比例。

## 设计

日历保留浅色模式已有的指标语义，并为深色模式提供同色相、适合深色卡片的独立渐变：睡眠为紫色、饮水为蓝色、饮食为橙色、运动为粉红色、体重为青色、服药为红色。热量缺口继续使用绿／红表达缺口与盈余。每个渐变都从低亮度底色过渡到高亮强调色，日期文字继续通过背景亮度自动选择黑白前景色。

底部导航采用 Material 3 风格的圆角悬浮容器。五个入口和导航状态保持不变，图标改用 Material 圆润线性图标，选中项使用胶囊形背景、主题强调色和稍强图标权重；未选中项使用低强调前景色。导航保留系统手势区内边距和语义化选中状态。

首页主进度条采用“循环覆盖”表达任意比例。第一轮 0%–100% 使用主题主色；超过 100% 后从左侧重新开始，以另一颜色覆盖相应比例；每完成一整轮，底色切换为刚完成轮次的颜色，下一轮使用新颜色继续覆盖。例如 130% 显示绿色满条上左侧 30% 红色，230% 显示红色满条上左侧 30% 紫色。比例不设上限，颜色按有限调色板循环。

## 验证

- 纯 Kotlin 单元测试覆盖循环进度在 0%、75%、100%、130%、200%、230% 和无效输入下的轮次与比例。
- `testDebugUnitTest` 验证逻辑回归。
- `assembleDebug` 验证 Compose 与 Android 资源编译。
- Android Studio 手测浅／深色日历七项指标、五个底栏入口，以及 80%、130%、230% 三种首页进度。

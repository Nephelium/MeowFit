# 日历指标适配与底部导航视觉更新设计

## 目标

修复 GitHub issue #2 中日历指标文字在部分窄屏或较大系统字体下换行的问题，同时允许用户在设置中控制日历显示的指标，并重绘底部导航图标。改动不得依赖具体手机型号，也不得改变日历数据、热力图计算、分享图内容或五个一级页面入口。

## 日历指标栏

日历继续支持睡眠、饮水、热量缺口、饮食、运动、体重和服药七项指标。界面先测量当前可见指标的文字宽度和胶囊内边距；全部文字能在指标栏单行容纳时显示中文，不能容纳时整栏统一切换为单字符 emoji。选择状态、点击范围和无障碍描述始终使用完整中文名称，不能因视觉上改用 emoji 而丢失语义。

设置页新增“日历显示项目”入口，以多选对话框控制可见指标。首次升级默认全部显示；保存时忽略未知值并至少保留“热量缺口”一项。偏好属于本机界面设置，写入现有 `ui_preferences` SharedPreferences，不修改 Room schema，也不进入业务备份。

## 底部导航

五个导航图标改为简化的 16×16 像素贴纸风格：今日使用猫爪、运动统计使用哑铃、日历使用台历、分析使用柱状图与闪光、设置使用滑杆。图形减少零碎像素，选中态增加实心面积和高光，未选中态保持简洁轮廓；既有文字标签、选中语义、点击行为和主题配色不变。

## 验证

纯 Kotlin 测试覆盖默认指标、过滤未知值、禁止空选择及宽度边界；随后运行全部单元测试和 Debug APK 构建。Android Studio 手测重点为窄屏、系统字体放大、隐藏部分指标、隐藏当前选中指标、深浅色主题和五个底部导航入口。

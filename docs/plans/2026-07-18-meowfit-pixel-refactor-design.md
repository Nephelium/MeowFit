# MeowFit 像素风完整重构设计

## 目标

在不丢失现有数据库和旧备份数据的前提下，修复静态审查发现的数据一致性、备份、AI、图片和更新逻辑缺陷；新增营养标签按重量与能量单位换算、自定义食物模板；将应用重构为带动态像素猫的完整像素健康手账，并保护首页长图与日历导出能力。

## 视觉系统

应用采用“像素猫咪健康手账”方向。标题、数字、按钮、图标、边框、阴影、进度条和图表使用像素语言；中文正文及输入内容使用清晰圆润字体。像素猫以程序化像素网格绘制，包含待机、眨眼、开心、困倦、喝水和庆祝状态，根据当日热量、饮水、睡眠与服药情况选择中性、非羞辱性的反馈。

主页强化状态层级；手动输入页分为快速输入与营养标签换算；日历页采用像素热力格、平滑趋势曲线、渐变面积和数据提示；统计、分析、设置、备份与资料页统一使用像素卡片和反馈组件。深色模式为星空夜猫配色。

## 数据与计算

数据库采用连续增量迁移。日常记录保存最终热量和营养素，同时可选保存营养标签快照，以便编辑时恢复基准量、实际量、能量单位和原始数值。新增自定义食物模板表，支持 `g`、`ml` 与“份”三种计量方式。

换算比例为 `actualAmount / referenceAmount`；输入 kJ 时按 `kcal = kJ / 4.184` 统一转换为数据库中的 kcal。计算层为纯 Kotlin，拒绝空值、负值、非有限值和零基准量，显示最多两位小数但不以显示值反算。

## 兼容与恢复

保留当前 15→16 迁移并增加后续迁移；不使用破坏性迁移。备份使用版本化 ZIP，继续读取历史 JSON 和旧 ZIP。恢复前创建内部恢复点，完整读取并校验备份，再以单一事务合并写入；失败整体回滚。旧备份缺少的新字段使用安全默认值，现有服药时间等数据不会因缺字段被清空。

新版备份纳入记录图片、AI 对话图片、自定义图标、自定义食物模板、周报和提示词，但不包含 API Key。恢复完成后按记录明细重新计算受影响日期的派生合计。

## 分享与导出保护

首页长图和日历图通过独立 Share Model 与 Renderer 生成，不从 Compose 画布截图。重构保留备注、体重遮罩、服药信息、记录图片、超长图限制、预览、MediaStore 保存、PNG 编码和 FileProvider 分享。像素化只替换绘制规范，不改变数据选择和隐私语义；新 Renderer 通过固定数据样例对照后才替换旧实现。

## 错误与验证

数据库和备份错误返回结构化结果；UI 显示可理解提示。图片预处理在 IO 线程采样解码，并限制数量和尺寸。验证覆盖营养换算、资料字段保留、AI 配置保留、全局/周报会话隔离、批量聚合、Room 迁移、旧备份恢复、新备份往返和导出关键组合。最终运行单元测试与 Debug 构建，真机视觉和分享由 Android Studio 手测清单补充。
